# Security policy

Arena Passport находится в стадии MVP. Не публикуйте описание уязвимости в issue.

Сообщение должно содержать затронутый маршрут/компонент, минимальные шаги воспроизведения, ожидаемый ущерб и безопасный способ связи. Не прикладывайте реальные пароли, токены, документы игроков или claim evidence. До появления выделенного security mailbox сообщения принимает владелец закрытого репозитория.

Поддерживается только текущая ветка `main`. Критические исправления проходят review, automated security baseline, полный test/build и отдельную проверку миграций. Секреты хранятся вне Git; обнаруженный секрет немедленно отзывается и заменяется.
