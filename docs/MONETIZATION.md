# Монетизация cyberID

Статус: тарифная матрица, UI, рекламные места и модель `Subscription` реализованы. Реальные списания отключены до выбора эквайринга, договора, оферты и webhook-подписи.

## Правило доступа к статистике

| Возможность                     | B2C Free | B2C Premium           | B2B Team    | B2B Pro                 |
| ------------------------------- | -------- | --------------------- | ----------- | ----------------------- |
| Публичный профиль verified-only | да       | да                    | да          | да                      |
| Подробные события               | 3 дня    | весь архив            | весь архив  | весь архив              |
| Сводные показатели              | 7 дней   | 30/90/365/вся карьера | все периоды | все периоды             |
| Сравнение и watchlists          | —        | да                    | общие       | общие + alerts          |
| Экспорт                         | —        | персональный PDF      | CSV 5k/мес  | API + повышенные лимиты |
| Реклама                         | да       | нет                   | нет         | нет                     |

Ограничение должно применяться в API, а не только скрывать элементы интерфейса. Исторические endpoints получают entitlement `statistics.archive.read`; экспорты — `statistics.export`; API — отдельный ключ организации, rate limit и audit.

## Тарифы

- B2C Free — 0 ₽.
- B2C Premium — 499 ₽/месяц.
- B2B Team — 14 900 ₽/месяц, 3 места.
- B2B Pro — 49 900 ₽/месяц, 10 мест и API.

Это стартовая гипотеза, а не публичная оферта. До запуска цены проверяются интервью, тестом конверсии, unit economics и налоговой моделью.

## Billing flow

1. Backend создаёт checkout у выбранного провайдера.
2. Только подписанный webhook создаёт или изменяет `Subscription`.
3. UI никогда не активирует права по успешному redirect без webhook.
4. При `PAST_DUE` действует grace-period, затем архив закрывается, но данные пользователя не удаляются.
5. Отмена сохраняет доступ до `currentPeriodEnd`.

## Реклама

Рекламный слот отделён от рейтинга и скрывается для платных планов. Каждое размещение получает disclosure «Реклама», даты кампании, frequency cap, UTM и отчёт. Партнёр не может влиять на PPR, публикацию или модерацию. Стартовый прайс находится на `/partners`.
